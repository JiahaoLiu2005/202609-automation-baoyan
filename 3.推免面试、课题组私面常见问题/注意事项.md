# 课题组私面注意事项

**1.** 课题组私面通常采用腾讯会议线上面试，建议提前找到一个安静且光线良好的房间，比如酒店钟点房、单人面试间等。面试时应提前调试电脑设备，主动打开麦克风、摄像头，通常不用双机位

**2.** 面试时如有机会操作电脑，一般只能做简单的PPT翻页操作，当你主动提出能否画一个流程图或者写一段代码方便老师理解，老师一般会让你口头表达，不要依赖电脑。但是，课题组私面可能会有临时的代码考核，比如让你写一段简单的代码完成指定的任务，一般20行以内就能解决

**3.** 如果是面试一个大的课题组，可能会出现要面试两轮甚至三轮的情况：第一轮博士生面试，博士生通常会关注你的项目细节，甚至可能具体到某个具体参数设置为多少，为什么这么设；第二轮小导面试，问的问题通常会宽泛一些，比如你这个项目有什么应用价值，详细展开一下你提到的这个trade-off，也可能是让你读论文写阅读报告；第三轮大老板面，这个细节我也不知道，因为这个情况我只碰到过一次，在小导面的时候被刷了

**4.** 无论如何不要露怯，迷之自信说是（）

**5.** 课题组私面通常只会问项目，没有英语和专业课环节，30分钟左右是正常现象。但是如果你是纯绩点er或者项目比较水，可能会碰到一直拷打专业课的情况

**6.** 面试后要求你提前进组是push的标志

**7.** 面试时说导师的某个研究方向与你的项目对口即可，不建议说读过老师的某篇论文，否则对面会拷打你那篇论文的具体细节，回答不出来容易导致面试暴毙


# 正式推免面试注意事项

**1.** 学校面试通常是线下形式，在讲台上通过鼠标或翻页笔操作校方的电脑，PPT会帮你投屏到大屏幕上。需要准备好存放PPT的U盘，PPT按学校要求命名，如无要求，一般命名为“姓名-XX大学推免面试”

**2.** 面试时如有机会操作电脑，一般只能做简单的PPT翻页操作，当你主动提出能否画一个流程图或者写一段代码方便老师理解，老师一般会让你口头表达，不要依赖电脑。面试时不可能出现让你写一段代码的情况

**3.** 部分学校是线上面试，如西安交大人工智能学院、中科院空天院。建议提前找到一个安静且光线良好的房间，比如酒店钟点房、单人面试间等。面试时应提前调试电脑设备，主动打开麦克风、摄像头

**4.** 无论如何不要露怯，迷之自信说是（）

**5.** 正式面试一般会有专业课、英语问题和项目问题，有时候也会有思政类问题，只要你三观正常基本不会有问题

**6.** 不管是强com还是弱com，在面试前有联系导师是加分项，可能导致面试老师的打分对你有一定的倾斜

**7.** 如有提前联系老师，面试时可以说读过老师的某篇论文，但是必须保证你知道其中的一些细节和创新点且对面的老师没读过那篇论文。这是你有诚意的表现，可能导致面试老师的打分对你有一定的倾斜

**8.** 拷打技术细节是技术面，一直否定、质疑你的项目是压力面。压力面时不要露怯不要哭不要红温，多微笑+道歉，适当可以跟老师辩论几句，主要还是顺着老师来
