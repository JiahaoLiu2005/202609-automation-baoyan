项目内容：针对合成图像归因问题构建双分支网络，利用EfficientNetV2与TAP模块提取空域特征，DWT-CNN提取频域特征，Concat后进行分类。另外采用了CutMix、Mixup、EMA、多尺度TTA、伪标签法、集成学习等trick


（1）为什么这么设计
合成图像在空域和频域都有独特伪造痕迹，单一分支难以全面捕捉。RGB分支提取空间纹理特征，DWT分支捕获频域伪影，双分支互补提升溯源精度

（2）网络架构是什么
双分支网络：RGB分支使用EfficientNetV2-L提取特征后经TAP注意力模块；灰度分支经Haar离散小波变换后送入CNN。两分支特征拼接后经全连接层分类为10类

（3）数据是怎么预处理的
图像缩放到384×384，归一化到[-1,1]。训练时应用CutMix、Mixup、高斯模糊等数据增强

（4）损失函数是怎么设计的
使用带标签平滑(0.1)的交叉熵损失。训练集用了MixUp、CutMix增强，要采用软标签加权损失，伪标签样本降低权重至0.5，防止噪声标签过度影响


（5）调了哪些参数
在伪标签法微调的时候，学习率从1e-5下调到1e-6，EMA衰减系数0.999，MixUp/CutMix概率0.5，伪标签权重0.5

（6）怎么评估的模型性能
五折交叉验证，每折用验证集计算准确率和损失。最终用测试集评估，配合多尺度TTA和加权集成，排行榜准确率99.7%

（7）TAP的结构和作用
可学习的查询向量与图像特征做交叉注意力，输出聚合特征。可以自适应关注与溯源任务强相关的特征，避免过度关注某些Token，减少背景噪声干扰。加入TAP模块后，准确率可以提升0.2%到0.3%

（8）为什么选择EfficientNetV2
参数量适中、训练快、表现强。而且这种网络的渐进学习策略和高效通道注意力适合高分辨率图像。对比实验表明，这个比赛中EfficientNetV2优于ConvNeXt-B，ConvNeXt-T，ResNeXt50，DINOv2 ViT-S等模型，准确率差距在0.3%以上

（9）为什么DWT比DFT效果好
DWT保留空间位置信息，可同时分析低频轮廓和高频纹理，符合图像局部伪造特性。DFT全局频谱丢失空间定位，对局部伪影不敏感。实验表明，引入DWT分支后准确率上升约0.2%，而引入DFT分支反而会导致准确率下降0.1%

（10）遇到的困难与解决方法
StableDiffusion不同版本混淆。解决方案是，引入DWT频域分支捕捉生成模型独有的高频伪影，提高准确率约0.2%。

（11）EMA及其在项目中的作用？
EMA是指数移动平均，以0.999的衰减率得到模型参数的滑动平均值。可以平滑参数波动，相当于隐式模型集成，避免参数剧烈抖动

（12）CutMix和MixUp是什么
MixUp：两张图像按比例像素混合，标签按相同比例软混合。
CutMix：将一张图像的矩形区域裁剪粘贴到另一张上，标签按面积比例混合。
可以增强泛化，防止过拟合，两者互补使用。

（13）多尺度TTA是怎么做的
推理时对每张图像生成6个增强版本：原始384、水平翻转、缩放到256、256翻转、缩放到480、480翻转。分别输入模型得到概率，取平均作为最终预测，提升准确率约0.2%。另外，如果把水平翻转换成垂直翻转，准确率反而会下降0.1%

（14）双卡并行训练是怎么实现的
使用subpross多进程，每张卡独立训练一个模型。主进程监控两个子进程，等待完成后收集结果。相比单卡串行训练，耗时减少约30%。

（15）伪标签法是怎么做的
用训练好的模型预测测试集，取高置信度（概率>0.9）的样本作为伪标签。测试集一共3000张图像，可以得到大概2800个高置信度样本。我们还试过把置信度阈值设为0.9，0.95和0.85，得到的样本数相差比较小，不到100，最后选了0.9，经验值。把它们与真实训练数据混合，伪标签样本的权重降低至0.5，重新微调模型，迭代5次，保存验证集准确率最高的模型

（16） DWT后面那个CNN为什么不用更大更深的模型
更大的CNN会过拟合。当前4层卷积足够提取判别特征，之前试过增加到6层，训练变慢，而且准确率没有提升

（17）EfficientNetV2优于DINOv2的原因
DINOv2依赖海量训练图像，但是本赛数据量小（10000张），自监督学习难以充分发挥作用。EfficientNetV2这样的卷积结构更适合小数据，微调收敛更快且不易过拟合。

（18）DINOv2介绍
一种自监督Vision Transformer，使用大量图像自监督学习训练，无需标签即可学习强大视觉特征。在ImageNet上达到SOTA，擅长密集预测任务，但需要大规模数据微调。

（20）改进的加权集成方法具体是怎么改进
综合考虑各模型预测一致性、最高置信度以及加权平均置信度三个指标，给予三者不同的权重，最终选出概率最大的几个类别。
具体而言，传统方法仅用加权后的平均概率，我增加了一致性得分和最高置信度两个指标。一致性得分是指某类别出现在多少模型的Top-3预测中，最高置信度是全部模型对该类别的最大概率。最终得分 = 0.3×加权概率 + 0.3×一致性 + 0.4×最高置信度，对争议样本更鲁棒。

（21）为什么频空融合用简单拼接
拼接保留了双分支的独立信息，让分类器自适应学习各特征的权重。之前尝试过交叉注意力，DWT特征作为Query，RGB特征作为Key/Value。输出融合特征再分类，效果比拼接低约0.6%，产生过拟合

（22）标签平滑是怎么做的
标签平滑将硬标签（one-hot）变为软标签：`y_smooth = y_onehot × (1-ε) + ε/K`，其中ε=0.1，类别数K=10。可以防止模型过度自信，强制输出概率不极端，提升泛化性。

（23）梯度累积的作用
每批次计算损失后反向传播但不更新参数，累计梯度accum_steps=4次后再执行`optimizer.step()`。可以等效增大batch size（16→64），稳定训练，突破单卡显存限制。

（24）EfficientNetV2的结构？相比V1的优势？
改进点：渐进学习策略（训练中动态增大图像尺寸和正则化强度）、Fused-MBConv模块训练更快且参数更少。结果：同精度下训练速度提升3-5倍，显存占用更低。

（25）拼接后是具体是怎么进行分类的
拼接后→LayerNorm→Dropout→Linear(512)→GELU→Dropout→Linear(10)。用LN原因：DWT和RGB特征分布差异大，BatchNorm依赖批次统计不稳定；LN逐样本归一化，适合异构特征融合
PS：GELU为高斯误差线性单元


（26）这个比赛的任务是什么，如果有个图片是其他AI工具生成的，模型能不能看出来
这个比赛的任务是合成图像归因，就是分辨给出的图像具体是由哪一种AI工具生成，比如不同版本的稳定扩散模型。因为数据集包括10种AI工具生成的图像，所以也可以看成图像的十分类问题。如果混入一张其他AI工具生成的图片，因为数据集的局限性，模型不一定能识别出来

（27）介绍一下T4显卡，它与别的显卡比如P100，5090有什么区别
Kaggle平台提供两种GPU环境，分别是T4双卡与P100单卡。T4显卡有16GB显存，INT8推理速度比较快，功耗小；P100显卡出的时间比T4早一点，也是16GB显存，但是功耗比较大，训练速度也不如T4；5090显卡训练速度是三种显卡里面最高的，但是功耗比较大，价格昂贵

（28）网络内部结构与特征对齐
输入尺寸：[B, 3, 384, 384]（RGB图像）（B表示批次大小batch size）
①空域
EfficientNetV2-L编码：输出特征图[B, 1280, 12, 12]（下采样32倍）
（EfficientNetV2-L固定输出通道数num_features = 1280，12是下采样得384 ÷ 32 ）
TAP：
将特征展平为 `[B, 144, 1280]`
交叉注意力（4个查询×8头×64维）→ `[B, 4, 512]` → 平均得 `[B, 1280]`
②频域
DWT分支：
输入RGB → 灰度（1通道）→ Haar小波分解为4通道 `[B, 4, 192, 192]`
（输入 [B, 3, 384, 384]转灰度变成[B, 1, 384, 384]；Haar DWT每2×2生成4系数，得到[B, 4, 192, 192]，因为384÷2=192；送入CNN第一个卷积层）
CNN降采样 → 全局池化 → `[B, 256]`
③特征对齐与融合
两分支输出直接拼接：`1280 + 256 = 1536维`
LayerNorm对齐分布 → Dropout → Linear(1536→512) → GELU → Linear(512→10)
输出：`[B, 10]` 类别logits

（29）DWT具体是怎么计算的
用的是Haar小波，把一个2×2的像素块拆成4个值
LL（低频近似）= 四个值的平均，保留整体结构
LH（水平细节）= (左上+右上)−(左下+右下)再除以2，捕捉水平边缘
HL（垂直细节）= (左上+左下)−(右上+右下)再除以2，捕捉垂直边缘
HH（对角细节）= (左上+右下)−(右上+左下)再除以2，捕捉对角线纹理
