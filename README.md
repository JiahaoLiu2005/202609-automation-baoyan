# 自动化专业保研资料（编写时间：2026年9月）

## 作者是谁

煮波是今年的保研生，最后是从湖南大学自动化保研到复旦大学电子信息。煮波的项目主要是关于计算机视觉，另外也涉及了一些机器人、传统机器学习和大模型微调的知识，所以这个项目对传统控制的同学可能帮助不大。另外煮波的项目是以竞赛为主，另外还有一些开源贡献，但是没有发过什么论文，只有一点水水的科研经历，所以这个项目对论文佬和纯绩点er可能帮助不大。本项目仅代表个人观点，请谨慎辨别。

煮波当时的情况：6项国际级竞赛，5项国家级竞赛，最佳战绩是某计算机视觉国际会议竞赛全球第二名、某机器人竞赛全国第三名。有Kaggle平台的Competitions Expert和Notebooks Expert称号，在积分榜上排名全球前1%。在GitHub上开源过一些竞赛资料，加起来差不多100 Stars。科研方面只有水水的项目和软著（技能树点的有点歪，有些老师表示从来没见过这种学生还挺新鲜）。承蒙老师们看得起，煮波最后是拿了中科大6系、上交未来技术学院、复旦电子工程系、东南自动化院、中山电通院、中科院空天院的优营，浙大工程师学院、南大机器人学院的候补

## 今年的夏令营预推免形势

保研夏令营大规模取消，即使没有取消，很多夏令营也不发铁offer，比如西安交通大学自动化院夏令营纯线上宣讲，中山大学电子与通信工程学院结果不公布。就算一个夏令营会发铁offer，那也是比较海或者bar比较高，比如上海交通大学溥渊未来技术学院今年超发优营，导致很多人拿了优营但是不铁。又比如中国科学技术大学信息科学技术学院入营强制要求导师推荐，导致每个导师的邮箱可能收到几十封甚至几百封邮件，但是最后只能推荐一两个进去，于是最后进了一堆大佬，再加上科大夏令营开得早，那些本来能去清北的大佬都来拿科大保底，导致很多真心想来的人被挤掉。

因为很多大佬在夏令营没拿到offer，于是他们在预推免阶段继续海投。按照往年的定位，如果一个人能去中9，但是因为前面的大佬在海投，这个人会硬生生被挤掉，最后可能就只能进末9的预推免。于是，第一梯度的大佬在预推免阶段拿到了大量的offer，而第二第三梯度的同学因为名额被挤压，最后拿不到满意的offer，就只能继续海投同时等鸽子链。最后产生的情况就是，今年的保研非常混乱，有很多学校都差点被鸽穿。

到了2027年，更多的夏令营会被取消，到时候的局面可能更混乱。而且因为保研人数在涨，竞争会越来越大。前几年可能成绩不错，有几个不错的比赛就能去好学校；后面可能没有硬核的比赛或者论文就要被压着打。反正如果打算保到水平比较高的外校的话，除了卷成绩，最好还是要有不错的竞赛和科研

## 这个项目是做什么的

主要是分享自动化专业保研相关的资料以及常见问题，包括专业课复习、英语面试等。当然，这里的一些资料对于考研生的复试应该也有帮助，毕竟面试无非就是英语、专业课、项目之类的，技巧和问题有很多都是通用的

这个项目最初是给希望保研到更高水平的外校的同学准备的。如果是打算保本校或者层次基本相同的学校，应该用不上这么多东西，只要态度好一点应该就问题不大
